ALMAS ESTAMPADAS — PUBLICAÇÃO E GERAÇÃO REAL DE IMAGENS POR IA

O que este projeto contém
- Loja responsiva em index.html
- Carrinho e finalização por WhatsApp
- Assistente que chama a API de imagens no servidor
- Limite simples de 4 pedidos de geração por minuto por IP
- Chave da API guardada no ambiente do servidor, nunca no navegador

ANTES DE COMEÇAR
A geração por API pode gerar cobranças separadas da assinatura do ChatGPT. Como é preciso configurar conta, chave e forma de pagamento, peça a um responsável adulto para cuidar dessa etapa e acompanhar os gastos. Nunca envie sua chave por chat, e-mail ou publique em arquivos.

PUBLICAR NO RENDER (método sugerido)
1. Extraia o ZIP no computador.
2. Crie um repositório PRIVADO no GitHub e envie os arquivos desta pasta para ele. Não envie nenhum arquivo .env real. O .gitignore já bloqueia .env e node_modules.
3. No Render, escolha New > Web Service e conecte o repositório privado.
4. Configure:
   Build Command: npm install
   Start Command: npm start
5. Na área Environment do serviço, adicione:
   OPENAI_API_KEY = sua chave secreta da API
   OPENAI_IMAGE_MODEL = gpt-image-2.5-sunburst
   (Não precisa definir PORT; o Render fornece essa variável.)
6. Clique para criar/publicar o serviço e aguarde o deploy terminar.
7. Abra a URL pública fornecida pelo Render. Para testar a API, acrescente /health à URL; deve aparecer JSON com "ok":true e "imageAIConfigured":true.
8. Na loja, abra o Assistente Almas e peça uma estampa original. A primeira geração pode demorar. Se falhar, confira os logs do Render e a configuração da API.

CHAVE DA API
- A chave é criada no painel da plataforma de API da OpenAI.
- A API tem faturamento separado do ChatGPT. Verifique preço, limites e saldo antes de ativar.
- Copie a chave diretamente para Environment no Render. Nunca a cole no index.html, no GitHub ou em mensagem pública.
- Se a chave for exposta, revogue-a e crie outra.

IMPORTANTE
- O site ainda é um protótipo de loja: confirme preços, estoque, frete, pagamentos, política de privacidade e regras de troca antes de vender de verdade.
- O botão do WhatsApp encaminha o pedido para conversa; não processa pagamentos automaticamente.
- O plano gratuito de hospedagem pode dormir após inatividade e a primeira visita seguinte pode demorar.
- O limite de solicitações reduz abuso, mas não substitui limites de gastos configurados na conta de API.
